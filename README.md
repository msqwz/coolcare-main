# CoolCare PWA & Admin Panel

Комплексная система для управления сервисным центром по ремонту и обслуживанию кондиционеров. Включает мобильное приложение для мастеров (PWA) и полноценную CRM-панель для диспетчеров и администраторов.

## Возможности

### 🛠 Мобильное приложение (PWA)
- **PWA** — установка на телефон, работа в оффлайне (Service Worker + IndexedDB).
- **Заявки** — полный цикл работы: от назначения до закрытия (статусы, чек-листы, услуги).
- **Оффлайн-режим** — создание и редактирование заявок без интернета с автоматической синхронизацией при появлении сети.
- **Оптимизация** — автоматическое построение маршрутов между объектами.

### 📊 Панель управления (Admin Panel)
- **Минималистичный Дизайн** — современный высококонтрастный интерфейс в стиле "Premium SaaS" (Indigo/Slate палитра).
- **Продвинутая Аналитика** — интерактивный дашборд с метриками выручки за 7 дней, среднего чека, конверсии и распределения услуг.
- **Ролевая модель (rbac)** — поддержка ролей:
  - **Администратор** — полный доступ ко всем функциям и управлению персоналом.
  - **Оператор** — настраиваемый доступ. Администратор может гибко включать/выключать доступ к Дашборду, Картам, Списку мастеров и т.д.
  - **Мастер** — доступ только к своим заявкам через PWA.
- **Мониторинг на карте** — плавающая стеклянная панель (Glassmorphism) для отслеживания местоположения мастеров и координат заявок в реальном времени.
- **Управление услугами** — конструктор прайс-листа с быстрым добавлением в заказы.

## Технологии

| Слой      | Стек              |
| --------- | ----------------- |
| Frontend  | React 18, Vite 5, Lucide Icons, Glassmorphism CSS |
| Backend   | FastAPI (Python 3.10+), SQLAlchemy/Supabase-py |
| БД        | Supabase (PostgreSQL) |
| Карты     | Yandex Maps API v2.1 |
| Auth      | JWT, SMS/Telegram OTP |

## Установка

### Локальная разработка

```bash
# 1. Backend
cd backend
python -m venv venv
source venv/bin/activate # или venv\Scripts\activate на Windows
pip install -r requirements.txt
# Настройте .env на основе .env.example
python main.py

# 2. Admin Panel (Dispatcher)
cd dispatcher
npm install
npm run dev
```

### Деплой на VPS (Ubuntu)
Для быстрого обновления и развертывания используйте автоматизированный скрипт:
```bash
bash deploy.sh
```
Скрипт автоматически собирает фронтенд, обновит зависимости бэкенда, применяет миграции и перезапускает сервисы через systemd/nginx.
